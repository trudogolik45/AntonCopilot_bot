# VPS с одним процессом, а не serverless

Бот живёт одним Python-процессом на VPS (Docker Compose, PostgreSQL в соседнем контейнере) и получает обновления через polling. Serverless (например, Yandex Cloud Functions) рассматривали: он снимает администрирование, но требует webhook, отдельных сервисов для отложенных задач (60 секунд тишины перед Черновиком, протухание Черновика через 24 часа) и managed PostgreSQL, который дороже VPS. При одном Владельце и десятках сообщений в день serverless ничего не экономит, а таймеры усложняет — поэтому VPS.
