## 2. Мой выбор стека

| Компонент   | Технология                           |
| ----------- | ------------------------------------ |
| Язык        | Python 3.12+                         |
| Telegram    | aiogram 3                            |
| AI          | OpenAI API или Anthropic API         |
| Backend     | FastAPI (когда понадобится HTTP API) |
| База данных | PostgreSQL                           |
| ORM         | SQLAlchemy 2                         |
| Хостинг     | VPS + Docker Compose                 |
| Мониторинг  | Sentry + структурированные логи      |

Не нужно: Kubernetes, Kafka, микросервисы, Redis, LangChain.

Для первой версии достаточно одного Python-процесса с aiogram, LLM API и SQLite. PostgreSQL добавляем, для хранение истории и настроек.

## 3. Как будет работать MVP

1. Человек пишет тебе в личку.
2. Telegram передаёт сообщение боту через Business Connection.
3. LLM определяет, относится ли сообщение к работе.
4. Если да — составляет ответ в твоём стиле.
5. Бот отправляет ответ от твоего имени либо сначала предлагает тебе его одобрить.

Начнем с режима одобрения ответов, чтобы AI случайно не пообещал клиенту то, чего ты не собирался делать.
