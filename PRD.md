# AntonCopilot — PRD

Личный Telegram Business Bot. Подключается к аккаунту Владельца, на каждое Входящее сообщение готовит Черновик ответа в стиле Владельца и отправляет его от имени Владельца только после Одобрения.

Термины — в `CONTEXT.md`.

## Стек

| Компонент   | Технология                                        |
| ----------- | ------------------------------------------------- |
| Язык        | Python 3.12+                                      |
| Telegram    | aiogram 3, polling, Business Connection           |
| LLM         | OpenRouter, `anthropic/claude-haiku-5.5` (в конфиге) |
| База данных | PostgreSQL, SQLAlchemy 2                          |
| Хостинг     | VPS `cpbox`, Docker Compose (см. ADR-0001)        |
| Мониторинг  | структурированные логи, без Sentry                |

Не нужно: Kubernetes, Kafka, микросервисы, Redis, LangChain, serverless, Sentry, HTTP API.

## Как работает MVP

1. Собеседник пишет Владельцу в личку. Telegram передаёт сообщение боту через Business Connection.
2. Бот сохраняет сообщение и ждёт 60 секунд тишины в этом чате.
3. LLM составляет один Черновик на всю пачку сообщений. Вход: `style.md`, Примеры ответа, последние 20 сообщений чата.
4. Бот присылает Черновик Владельцу в свой чат с кнопками **Отправить / Изменить / Отклонить**.
5. **Отправить** — бот отправляет Черновик от имени Владельца. **Изменить** — Владелец присылает свой текст, бот отправляет его как есть и сохраняет как Пример ответа. **Отклонить** — ничего не отправляется.

## Правила

- **Владелец один.** Его Telegram ID бот берёт из Business Connection. На остальных пользователей бот не реагирует.
- **Чаты:** все личные чаты, которые Владелец открыл боту в настройках Telegram Business. Своего списка нет.
- **Фильтра нет:** Черновик готовится на каждое Входящее сообщение.
- **Типы сообщений:** текст и подписи к фото. Голосовые, файлы, стикеры и прочее пропускаются (голосовые — следующий шаг).
- **Новое сообщение** при висящем Черновике — Черновик пересобирается и заменяет старый.
- **Правка** сообщения Собеседником — Черновик пересобирается. **Удаление** — Черновик отменяется.
- **Владелец ответил сам** — Черновик отменяется (если бот видит исходящие Владельца, см. «Проверить»).
- **Просроченный черновик:** если окно ответа Telegram (24 часа с последнего Входящего сообщения) закрылось, кнопки убираются, бот пишет «Не успел, ответь сам».
- **Стиль:** общий — `style.md` в репо; плюс Примеры ответа из правок Владельца (в БД); плюс тон конкретного чата из последних 20 сообщений.
- **Ошибка LLM:** одна повторная попытка, затем сообщение Владельцу «Не смог составить черновик для <имя>».
- **Хранение:** не больше 20 сообщений на чат, старые удаляются.
- **Только Одобрение.** Автоотправки в MVP нет.

## Проверить на живом боте

- Приходят ли исходящие сообщения Владельца боту как `business_message`. От этого зависят отмена Черновика при ответе Владельца и тон чата из его собственных реплик.
